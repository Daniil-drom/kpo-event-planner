# Выполненная работа — 21 октября 2026 года

Исторический отчёт о подготовке каркаса. Актуальное состояние проекта — в [README](../README.md), локальный запуск — в [инструкции для Windows](LOCAL_POSTGRESQL.md).

Подготовлен технический каркас проекта по согласованному стеку. Это основа для дальнейшей реализации, а не готовый MVP.

| Область | Что подготовлено |
| --- | --- |
| Сервер | Spring Boot 3.5.16, Java 17, Maven, основной класс приложения |
| База | Flyway V1: 9 таблиц, внешние ключи, индексы и ограничения; V2: Санкт-Петербург, Москва, Екатеринбург |
| API | GET /api/cities читает города из PostgreSQL |
| Интерфейс | HTML/CSS/JavaScript, загрузка городов из API, сообщения о пустом каталоге и ошибке |
| Логирование | Метод, путь, статус, длительность HTTP-запроса в STDOUT; тело, cookie и query string не логируются |
| Модульные тесты | Два теста логирования, в том числе отсутствие чувствительных полей |
| Интеграционные тесты | Пять сценариев: API городов и ограничения пользовательских посещений |
| Запуск | Dockerfile, Compose с основной и отдельной тестовой БД, Bash-скрипт сборки, тестов и запуска |
| CI | GitHub Actions: сборка и тесты с PostgreSQL при push и pull request, сохранение отчётов |
| Документация | Инструкции запуска, сохранённое описание этапов 1–3, следующие задачи и критерии готовности |

## Проверки

- Maven package на Java 17: BUILD SUCCESS, JAR создан.
- JUnit: 2 теста, 0 ошибок, 0 пропусков.
- SQL-миграции дополнительно проверены в PGlite (PostgreSQL в WebAssembly): созданы 9 таблиц и 3 города; проверены ограничения интервалов и удаления события с сохранённым посещением.
- JavaScript: синтаксическая проверка node --check.
- Bash: синтаксическая проверка bash -n.
- YAML и pom.xml: проверка разбора; проверка пробелов git diff --check.

Полный запуск Docker Compose, Java-интеграционные тесты FoundationIT и CI в GitHub ещё не выполнены: в среде подготовки нет Docker и отдельного сервера PostgreSQL. PGlite проверяет SQL, но не заменяет проверку приложения через JDBC и Docker.

## Что ещё не реализовано

Импорт KudaGo, поиск и карточки мероприятий, регистрация и вход, персональные планы, проверка пересечений, бизнес-тесты и сквозная пользовательская история. Текущие тесты не закрывают весь этап тестирования дисциплины.

Внешние данные ещё не загружаются. Экран не имитирует готовый каталог. Сервер предоставляет только чтение городов и проверку состояния.
